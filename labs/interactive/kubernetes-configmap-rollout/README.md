# Kubernetes ConfigMap Rollout

One-command challenge for understanding ConfigMap-backed environment variables and Deployment rollouts in a disposable K3s cluster.

```bash
docker run --pull=always --rm -it --privileged ghcr.io/marvy936/knowledge-hub-lab-docker-network-debug:latest kubernetes-configmap-rollout
```

The host needs only Docker. The lab exposes a `kubectl` wrapper inside the sandbox.
