# LocalStack S3 Versioning

A local AWS-compatible challenge. The learner enables S3 bucket versioning and creates a second version of an object using an `aws` wrapper bundled in the lab runtime.

```bash
docker run --pull=always --rm -it --privileged ghcr.io/marvy936/knowledge-hub-lab-docker-network-debug:latest localstack-s3-versioning
```

This lab validates LocalStack behavior only; it does not claim execution against a real AWS account.
